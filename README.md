# 💰 Cayla Finance

**Cayla Finance** adalah aplikasi manajemen keuangan pribadi dan keluarga yang modern, elegan, dan *privacy-focused*. Dirancang khusus untuk mencatat pengeluaran harian dengan fitur lampiran foto bukti transaksi.

🚀 **Live Demo:** [https://yere-boop.github.io/Tabungan/](https://yere-boop.github.io/Tabungan/)

---

## ✨ Fitur Unggulan

- **📸 Photo Attachment:** Lampirkan foto nota atau bukti pembelian langsung dari kamera atau galeri.
- **👥 Multi-Profile:** Kelola keuangan secara terpisah antara profil (Cayla & Yeremia) atau lihat gabungan keduanya.
- **📊 Interactive Dashboard:** Grafik tren pengeluaran, proporsi kategori, dan statistik bulanan yang interaktif.
- **📱 PWA Ready:** Bisa di-install di Android, iOS, atau Desktop seolah-olah aplikasi native.
- **🎨 Premium UI/UX:** Desain modern dengan dukungan *Dark Mode*, glassmorphism, dan animasi halus.
- **🔒 Privacy First:** Semua data disimpan secara lokal di browser Anda (Local Storage), tidak dikirim ke server mana pun.
- **📥 Export/Import:** Backup data Anda ke format JSON atau ekspor ke format Excel.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 & CSS3:** Custom design system dengan Glassmorphism.
- **JavaScript:** Pure Vanilla JS (No Framework).
- **Chart.js:** Untuk visualisasi data yang interaktif.
- **Lucide Icons:** Ikon vektor yang bersih dan modern.
- **SweetAlert2:** Untuk notifikasi dan modal yang cantik.

---

## 📱 Cara Install (PWA)

1. Buka [Link Aplikasi](https://yere-boop.github.io/Tabungan/) di browser smartphone Anda.
2. Klik menu **Share** (iOS) atau **Titik Tiga** (Android).
3. Pilih **"Add to Home Screen"** atau **"Install App"**.
4. Aplikasi akan muncul di layar utama HP Anda dengan ikon **Cayla Finance**.
